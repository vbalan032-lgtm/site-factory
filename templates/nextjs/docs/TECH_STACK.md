# Технический стек

- Next.js 16 App Router, React 19, TypeScript strict, Tailwind CSS 4.
- Server Components по умолчанию; Client Components только для интерактива.
- npm и lockfile; lint, typecheck, factory tests и build обязательны.
- Перед Next.js изменениями читать local Next.js 16 docs before Context7.
- Production-поставка совместима с standalone Docker; production требует отдельного согласования.
