# Design Skill Routing

## Authority

1. direct owner instruction
2. immutable brand core, claims discipline, Russian public-copy requirement, and technical/release constraints
3. approved page artifacts and approved Creative Blueprint
4. accessibility and web compliance
5. framework and component contracts
6. optional taste

An approved Creative Blueprint may override or supersede the visual baseline but cannot change or weaken immutable constraints. Russian approved artifacts outrank optional punctuation or style preferences.

| Owner | Tools |

| `02-creative-blueprint` | `design-taste-frontend` `ui-ux-pro-max` `shadcn` |

| `06-integrated-qa-refinement` | `web-design-guidelines` `vercel-react-best-practices` `design-taste-frontend` `shadcn` |

Specialists are review-only unless the owner stage requests a bounded artifact. Canvas is conditional static art. UI intelligence is for foundation or new archetype work. Do not load all design skills for one stage. State-only work uses no design tools.

At Stage 6, compliance and accessibility findings can block release and outrank taste. Read local Next.js 16 docs before Context7.

Task 5 prepares ownership and routing. `components.json` belongs to Task 5.5; do not initialize shadcn during routing work.
